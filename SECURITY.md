# Security policy

## Supported versions

Only the `main` branch is supported. There are no released versions.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: go to the **Security** tab of this
repository and click **Report a vulnerability**. Include the steps to
reproduce, what you expected and what happened.

I aim to reply within 7 days. This is a personal project, so fixes are
best effort.

## Scope

Wallet & Ledger is a portfolio demo. It handles fake money only.

- Do not enter real emails or passwords on the demo site; use a throwaway
  email or the demo account.
- In scope: the code in this repository and the demo deployment.
- Out of scope: denial-of-service tests against the demo, social
  engineering, and vulnerabilities in third-party services (AWS, GitHub).
